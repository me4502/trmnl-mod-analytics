TRMNL Mod Analytics

Micro-service to facilitate project analytics across various mod platforms. API Routes:

GET /api/modrinth/summary?project_ids=worldedit,worldguard
GET /api/curseforge/summary?project_ids=225608,254692
GET /api/thunderstore/summary?project_ids=lethal-company/ebkr/r2modman

Pass provider credentials in the Authorization header only. Tokens are forwarded to the selected provider and are not stored.
